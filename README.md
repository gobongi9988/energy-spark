# 시동

기분 전환·일상 시동용 모바일 웹앱. 빌드 없이 GitHub Pages에서 바로 돈다.

- **음악** — 기분 5개 중 하나를 고르면 유튜브로 바로 들을 수 있는 곡이 하나 나옴(좋아요 목록·기존 풀에서 45곡, 기분별 8~10곡). 앱 안 임베드 플레이어로 **전곡 재생**(임베드 가능 여부를 oEmbed로 확인한 영상만). 플레이어는 하단 고정 — 탭을 바꿔도 끊기지 않고 미니 바로 남음. 원하면 스포티파이 링크도 작게. 유튜브 링크를 붙여넣어 직접 추가·삭제(localStorage).
- **뽑기** — 집 안에서 바로 할 수 있는 것 17개(음악 틀기·몸풀기 동작 바로 시작·3분 타이머·새소년 라이브 영상). 지도/장소 링크 없음(장소는 산책 탭 몫). 지금 하기 + 했음. 직접 추가·삭제.
- **몸풀기** — 두 트랙. ① 스트레칭·요가 14개(동작명·**동작 그림 설명(SVG)**·횟수/세트·소요 시간·어디에 좋은지·자세 팁, 두피마사지·페이스요가 지압점/효과/횟수 포함). 그림은 자세 실루엣 + 움직임 화살표, 두피·페이스는 지압점과 혈자리 이름 라벨. + 이어서 하는 코스 2개('5분 입문 루틴', '책상에서 3분') ② 진짜 간단한 것 17개(창문 열고 햇빛 3분, 차 내려 마시기, 발목 돌리기부터 족욕·눈 수건·멍때리기 5종까지). 상단 '오늘 뭐 할까 · 랜덤 1개'로 바로 시작.
- **완료 축하** — 몸풀기·타이머·뽑기에서 완료하면 Web Audio 팡파레 + 콘페티가 터지는 축하 화면과 칭찬 한 줄(20종). 횟수·도장·게이지 같은 누적 표시는 없음.
- **3분** — 1·3·5분 타이머, Web Audio 차임벨. '같이 들을 음악'은 지금 고른 곡을 유튜브 플레이어로 그대로 틀어 줌(탭을 옮겨도 계속 재생).
- **산책** — 상계주공3단지 기준 코스 10개(15~50분). 지금 시간대에 맞는 코스만, 들를 곳마다 **`가보기` 버튼 하나**(네이버지도 검색으로 열림, 카카오맵 링크는 없음). 롯데백화점 노원점 리뉴얼·올리브영·노원문화의거리·노원아트뮤지엄·북서울미술관 무료 전시 포함. 아래에 **인스타에서 핫한 데 7곳**(빈스링·플로레스테이블·당현마루·블루마일스·뮤어카페·노원역 옛날칼국수·상계동원조닭갈비 동순집)을 영업시간·한 줄 설명과 함께 따로 모아 둠.

## 파일
- `index.html` — 화면 구조
- `styles.css` — 모바일 퍼스트, 라이트/다크
- `data.js` — 기분·유튜브 재생곡 45개·몸풀기(스트레칭·요가·간단한 것·코스)·좋아하는 것·산책 코스·인스타 핫플 기본값
- `art.js` — 몸풀기 14개 동작의 그림 설명 인라인 SVG(320×160, 카드 폭에 맞춰 스케일)
- `app.js` — 상태(localStorage), 렌더, 유튜브 플레이어, 타이머, 차임벨
- `assets/` — 닥스훈트 마스코트(헤더·파비콘·홈 화면 아이콘·축하 화면). `icon.png`·`icon.svg`는 예전 아이콘.

배포: https://gobongi9988.github.io/energy-spark/

## 배포 방식 (중요)
Pages는 `gh-pages` 브랜치를 서빙한다. 소스는 `main`에 두고, 수정 후에는 두 브랜치를 모두 밀어야 사이트가 갱신된다.

```
git push origin main
git branch -f gh-pages main && git push origin gh-pages
```

정적 파일 캐시 때문에 `index.html`의 `?v=` 값을 바꿔 주면 즉시 반영된다.
(GitHub App 권한상 Pages 설정 API는 막혀 있어, gh-pages 브랜치 푸시로 자동 게시됐다.)
