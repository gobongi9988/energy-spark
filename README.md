# 시동

기분 전환·일상 시동용 모바일 웹앱. 빌드 없이 GitHub Pages에서 바로 돈다.

- **음악** — 기분 5개 중 하나를 고르면 스포티파이 플레이리스트·곡 매칭(사용자 '애롱' 좋아요 211곡 중 중복 3건 제외 208곡 + 내 플레이리스트 9개 + 취향 추천 10곡 = 227개, 아티스트·장르·기분 태그와 목록 검색 지원). '스포티파이에서 바로 열기' 버튼(앱 유니버설 링크) + iOS에서 spotify: URI 링크 + 화면 안 임베드 플레이어. 링크를 붙여넣어 직접 추가·삭제(localStorage).
- **뽑기** — 집 안에서 바로 할 수 있는 것 17개(음악 틀기·몸풀기 동작 바로 시작·3분 타이머·새소년 라이브 영상). 지도/장소 링크 없음(장소는 산책 탭 몫). 지금 하기 + 했음. 직접 추가·삭제.
- **몸풀기** — 두 트랙. ① 스트레칭·요가 14개(동작명·횟수/세트·소요 시간·어디에 좋은지·자세 팁, 두피마사지·페이스요가 지압점/효과/횟수 포함) + 이어서 하는 코스 2개('5분 입문 루틴', '책상에서 3분') ② 진짜 간단한 것 17개(창문 열고 햇빛 3분, 차 내려 마시기, 발목 돌리기부터 족욕·눈 수건·멍때리기 5종까지). 상단 '오늘 뭐 할까 · 랜덤 1개'로 바로 시작.
- **완료 축하** — 몸풀기·타이머·뽑기에서 완료하면 Web Audio 팡파레 + 콘페티가 터지는 축하 화면과 칭찬 한 줄(20종). 횟수·도장·게이지 같은 누적 표시는 없음.
- **3분** — 1·3·5분 타이머, Web Audio 차임벨. 같이 들을 음악은 타이머 화면에서 ▶ 재생으로 스포티파이 임베드가 펼쳐지고, 앱으로 열기 링크도 있음.
- **산책** — 상계주공3단지 기준 코스 10개(15~50분). 지금 시간대에 맞는 코스만, 들를 곳과 카카오맵·네이버지도 링크. 롯데백화점 노원점 리뉴얼·올리브영·노원문화의거리·노원아트뮤지엄·북서울미술관 무료 전시 포함.

## 파일
- `index.html` — 화면 구조
- `styles.css` — 모바일 퍼스트, 라이트/다크
- `data.js` — 기분·플레이리스트·몸풀기(스트레칭·요가·간단한 것·코스)·좋아하는 것·산책 코스 기본값
- `app.js` — 상태(localStorage), 렌더, 타이머, 차임벨
- `assets/` — 닥스훈트 마스코트(헤더·파비콘·홈 화면 아이콘·축하 화면). `icon.png`·`icon.svg`는 예전 아이콘.

배포: https://gobongi9988.github.io/energy-spark/

## 배포 방식 (중요)
Pages는 `gh-pages` 브랜치를 서빙한다. 소스는 `main`에 두고, 수정 후에는 두 브랜치를 모두 밀어야 사이트가 갱신된다.

```
git push origin main
git branch -f gh-pages main && git push origin gh-pages
```

정적 파일 캐시 때문에 `index.html`의 `?v=` 값을 바꿔 주면 즉시 반영된다.
(GitHub App 권한상 Pages 설정 API는 막혀 있어, gh-pages 브랜치 푸시로 자동 게시됐다.)
