# 시동

기분 전환·일상 시동용 모바일 웹앱. 빌드 없이 GitHub Pages에서 바로 돈다.

- **음악** — 기분 5개 중 하나를 고르면 유튜브로 바로 들을 수 있는 곡이 하나 나옴(좋아요 목록·기존 풀에서 45곡, 기분별 8~10곡). 앱 안 임베드 플레이어로 **전곡 재생**(임베드 가능 여부를 oEmbed로 확인한 영상만). 플레이어는 하단 고정 — 탭을 바꿔도 끊기지 않고 미니 바로 남음. 원하면 스포티파이 링크도 작게. 유튜브 링크를 붙여넣어 직접 추가·삭제(localStorage).
- **뽑기** — 집 안에서 바로 할 수 있는 것 17개(음악 틀기·몸풀기 동작 바로 시작·새소년 라이브 영상). 지도/장소 링크 없음(장소는 산책 탭 몫). 지금 하기 + 했음. 직접 추가·삭제.
- **몸풀기** — **한눈에 보는 2열 그리드**. 카드에는 그림 + 동작 이름만 두고, 누르면 아래 시트에서 횟수·세트·소요 시간·어디에 좋은지·구체적 방법·지압점 도해를 다 보여 줌. 2026-11-28 개편으로 길게 펼쳐지던 손그림 SVG 설명은 없애고, 동작이 딱 보이는 클린 아이콘(`assets/moves/*.png`)으로 교체.
  - 요가·스트레칭 12개(목·승모근, 고양이-소, 아기 자세, 다운독, 가슴 열기, 무릎 당기기, 척추 비틀기, 나비, 까치발, 사이드, 손목, 의자 비틀기)
  - 지압·페이스 6개 — **두피마사지**(백회·태양·풍지·견정혈)와 **페이스요가 5종**(아침 붓기·눈 피로 / 턱선·이갈이 / 팔자·볼 리프팅 / 미간·이마 / 이중턱·목선). 각 항목은 혈자리 위치를 손으로 짚을 수 있게 해부학적으로 적고, 손가락·누르는 방향·힘·초·횟수·효과를 단계별로 넣음. 상세 시트에는 번호가 매겨진 얼굴/머리 도해(SVG)가 있어 번호와 설명이 짝을 이룸.
  - 이어서 하는 코스 2개('5분 입문 루틴', '책상에서 3분')
  - 간단한 거 17개(창문 열고 햇빛 3분, 차 내려 마시기, 발목 돌리기부터 족욕·눈 수건·멍때리기까지)
  - 상단 '오늘 뭐 할까 · 랜덤 1개'로 뽑으면 바로 그 동작 상세 + 타이머 시작.
- **완료 축하** — 몸풀기·코스·뽑기에서 완료하면 Web Audio 팡파레 + 콘페티가 터지는 축하 화면과 칭찬 한 줄(20종). 횟수·도장·게이지 같은 누적 표시는 없음.
- **산책** — 상계주공3단지 기준 코스 10개(15~50분). 지금 시간대에 맞는 코스만, 들를 곳마다 **`가보기` 버튼 하나**(네이버지도 검색으로 열림, 카카오맵 링크는 없음). 롯데백화점 노원점 리뉴얼·올리브영·노원문화의거리·노원아트뮤지엄·북서울미술관 무료 전시 포함. 아래에 **핫플 7곳**(빈스링·플로레스테이블·당현마루·블루마일스·뮤어카페·노원역 옛날칼국수·상계동원조닭갈비 동순집)을 **실제 메뉴·가게 사진 1장씩**과 영업시간·한 줄 설명으로 모아 둠.
- **3분 탭은 없음** (2026-11-28 사용자 요청으로 삭제). 탭은 음악·뽑기·몸풀기·산책 4개.

## 파일
- `index.html` — 화면 구조
- `styles.css` — 모바일 퍼스트, 라이트/다크
- `data.js` — 기분·유튜브 재생곡 45개·몸풀기(요가·지압/페이스·간단한 것·코스)·좋아하는 것·산책 코스·핫플 기본값(사진 경로 포함)
- `app.js` — 상태(localStorage), 렌더, 유튜브 플레이어, 동작 그리드·상세 시트·타이머, 차임벨
- `assets/moves/` — 몸풀기 35개 동작·생활 아이콘(PNG 340px, 흰 배경 투명 처리, 다크모드에서 CSS 반전)
- `assets/places/` — 핫플 7곳 실제 사진(4:3 크롭)
- `assets/` — 닥스훈트 마스코트(헤더·파비콘·홈 화면 아이콘·축하 화면). `icon.png`·`icon.svg`는 예전 아이콘.

## 배포 방식 (중요)
Pages는 `gh-pages` 브랜치를 서빙한다. 소스는 `main`에 두고, 수정 후에는 두 브랜치를 모두 밀어야 사이트가 갱신된다.

```
git push origin main
git branch -f gh-pages main && git push origin gh-pages
```

정적 파일 캐시 때문에 `index.html`의 `?v=` 값을 바꿔 주면 즉시 반영된다.
(GitHub App 권한상 Pages 설정 API는 막혀 있어, gh-pages 브랜치 푸시로 자동 게시됐다.)
